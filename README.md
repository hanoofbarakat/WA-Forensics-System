# WA-Forensics

## Overview

WA-Forensics is a digital forensic investigation system developed to recover and analyze deleted WhatsApp messages from Android devices. The system assists forensic investigators by analyzing WhatsApp artifacts while preserving evidence integrity.

---

## Features

- Recover deleted WhatsApp messages
- Analyze SQLite databases
- Analyze WAL files
- Support Crypt14/Crypt15 artifacts
- Timeline reconstruction
- Forensic report generation
- Evidence integrity verification

---
